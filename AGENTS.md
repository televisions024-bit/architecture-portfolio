# AGENTS.md — instructions for any coding model working in this repo

1. Read `PROJECT.md` fully before doing anything.
2. Follow `PROJECT.md` section 9 (working rules) and section 5 (design rules) exactly.
3. ONE task at a time. Never redesign pages you were not asked to touch.
4. NEVER overwrite the cover page (`index.html`) — it is marked DONE.
5. Update `CHANGELOG.md` (one line: date, what changed, files touched) and `TODO.md` after every task.
6. Content for project pages lives in `projects/*.json` — do not hard-code content into HTML.
7. Keep HTML/CSS/JS simple and commented; a beginner must be able to edit it.
