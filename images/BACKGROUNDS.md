# BACKGROUNDS.md — background image candidates, credits and treatment

Decorative page-backgrounds ONLY (PROJECT.md section 5, rule added 2026-11-01):
desaturated warm-grey versions of generic architecture stock photos. They are **never
used inside project image slots** and they are **not Mohammed's work**.

All files live in `images/backgrounds/` — each candidate as `name-1920.webp` (desktop,
target 150-250 KB) and `name-900.webp` (phone). Treatment applied during conversion
(originals untouched beyond that): grayscale + warm paper tint (#EBE6DD) + flattened
shadows so text stays readable on top. Flat b/w scenes compress far below 150 KB —
that is fine, the range is a target for HTTP-friendliness, not a gate.

Chosen by eye via `backgrounds-preview.html` (not linked from the site).
